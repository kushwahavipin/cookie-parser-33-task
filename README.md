# Task 33: Cookies and Response

This project demonstrates cookie handling and sending JSON data with various response codes using Express.js for the backend and React for the frontend.

## Deployed Links
- **Frontend:** [Vercel Frontend](https://cookie-parser-33-task-frontend.vercel.app/)
- **Backend:** [Vercel Backend](https://cookie-parser-33-task-backend.vercel.app/)


## Setup
1. Clone the repositories.
2. Install dependencies using `npm install`.
3. Run `npm start` to start the frontend and backend.

## Usage
- Set a cookie in the client's browser.
- Retrieve the cookie from the client's browser.
- Send JSON data with various HTTP status codes.
